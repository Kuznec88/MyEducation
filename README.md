# MyEducation

Study assignments and practice exercises completed during a Java development course on Skillbox.

This repository grew out of the learning process — from early labs on basic syntax
and OOP to more applied tasks. Written back when you still had to Google and
debug things yourself, without any AI assistance around 😄

## What's inside

- Practice assignments covering Java fundamentals and OOP
- Small learning projects used to reinforce course material

## Why it's here

Kept as an artifact from the early part of my dev journey — an honest look at
where I started before moving into test automation and API/UI frameworks
(see other repos, e.g. AlphaTestProject).

# MyEducation

Учебные задания и практические работы, выполненные в рамках курса Java-разработки на Skillbox.

Репозиторий собирался в процессе обучения — от первых лабораторных по основам синтаксиса
и ООП до более прикладных задач. Написано ещё в те времена, когда код приходилось
гуглить и дебажить самому, без нейросетей под рукой 😄

## Что внутри

- Практические задания по основам Java и ООП
- Небольшие учебные проекты для закрепления материала курса

я стартовал, прежде чем перейти в автоматизацию тестирования и API/UI-фреймворки
(см. другие репозитории, например AlphaTestProject).
